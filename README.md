# artigen — AI art community platform built with React Native, Expo, and Supabase

**Live:** <https://mukundakatta.github.io/artigen/>

AI art community platform built with React Native, Expo, and Supabase. artigen gives you a focused, inspectable implementation of that idea.

## Why artigen

artigen exists to make this workflow practical. Ai art community platform built with react native, expo, and supabase. It favours a small, inspectable surface over sprawling configuration.

## Features

- Test suite
- Dedicated documentation folder

## Tech Stack

- **Runtime:** Node.js, TypeScript
- **Frameworks:** React
- **Storage:** Supabase
- **Tooling:** Jest, ESLint, Prettier

## How It Works

The codebase is organised into `assets/`, `docs/`, `migrations/`, `patches/`, `public/`, `scripts/`.

## Getting Started

```bash
npm install
npm start
```

## Usage

```bash
npm start
```
