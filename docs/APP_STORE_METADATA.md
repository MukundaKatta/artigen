### Notes for Reviewers

Artigen is an AI art community platform. To test the core features:

1. Sign up or use the demo account above
2. Navigate to the Create tab to generate AI artwork using text prompts
3. Browse the Home feed to see community artwork
4. Try the social features: like, comment, follow users
5. Explore Communities, Challenges, and the Marketplace

Note: AI generation requires credits. The demo account has been preloaded with credits for testing purposes. Some AI models (marked as "Premium") require additional credits.

The app uses Supabase for authentication and backend services. All AI generation is performed server-side via edge functions.
