# HackerNoon Proof of Usefulness — Submission Drafts

Draft articles for the 9 projects scored in the HackerNoon Proof of Usefulness Hackathon. Each project is "60% ready" per HackerNoon — score generated, draft pending. Workflow per project:

1. Open the draft markdown file in this folder.
2. Edit/tighten in your voice. Add a hero image and screenshots where called out.
3. Paste into the HackerNoon draft editor via the "Finish My Submission" link from the alert email for that project.
4. Fill the title/subtitle/meta-description/TLDR/tags from [submission-metadata.md](./submission-metadata.md).
5. Submit to editors.

## Voice / framing notes

The hackathon scores on **real-world utility, not hype**. Every draft leads with a concrete failure mode the library prevents (silent egress, drifting tool order, JSON that won't parse, etc.), then shows the smallest possible code sample that proves it. No "revolutionizing AI" language.

Sponsors are Bright Data, Neo4j, Storyblok, Algolia, and HackerNoon. If a project naturally fits one of those tools (e.g., Neo4j for agentmemory's PG store), consider a follow-up sentence — but don't force it.
